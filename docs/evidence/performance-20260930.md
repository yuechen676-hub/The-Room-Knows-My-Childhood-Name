# 房间性能基线：2026-09-30

## 测量条件

- Unity 6000.3.7f1，Windows Development Player，Direct3D12，1920×1080。
- CPU：i5-13600KF；GPU：Radeon RX 6750 GRE 12GB；内存约 32GB。
- 可见窗口、关闭垂直同步、不限制帧率；每组预热 3 秒、固定起点水平转向 360 度采样 12 秒。
- 禁用 AI 会话、对话 UI 更新及玩家移动；用于比较初始阶段的渲染开销，不代表完整交互试玩、AI 延迟或所有六阶段。
- 编辑器仍开着；首尾重复基线基本一致。显卡计时有返回。
- `baseline.json` 是隐藏窗口试跑，跳过了正常绘制，**无效，不用于结论**。有效数据为 `visible-baseline.json`。

## 结果

| 临时测试配置 | 平均 FPS | 平均帧耗时 | P95 帧耗时 | 最慢帧 |
|---|---:|---:|---:|---:|
| 原设置 | 75.9 | 13.18 ms | 19.79 ms | 119.05 ms |
| 关闭镜面渲染 | 146.3 | 6.84 ms | 9.16 ms | 13.53 ms |
| 关闭实时阴影 | 161.7 | 6.18 ms | 9.04 ms | 16.13 ms |
| 镜面与实时阴影均关闭 | 252.8 | 3.96 ms | 6.16 ms | 7.29 ms |
| 渲染比例 75% | 86.2 | 11.61 ms | 18.32 ms | 110.52 ms |
| 恢复原设置复测 | 75.7 | 13.20 ms | 19.49 ms | 112.61 ms |

P95 表示 95% 的采样帧耗时不超过该数值。平均帧率会掩盖偶发停顿。镜面与阴影开销存在交互，不能将两项节省简单相加。

## 现场规模

1,434 个 Renderer，模型实例合计 9,061,273 个顶点（不是每帧可见顶点数），16 个启用投影的灯，5 个启用的实时镜面。

## 优化顺序

1. 先降低镜面开销：测试镜面内不再重复绘制实时阴影，降低反射分辨率与刷新频率；保留现有视锥及朝向判断。比较图像后决定是否采用，不全局删除镜面。
2. 梳理投影灯：保留重要接触阴影，减少装饰灯投影，针对房间实际尺寸调整阴影范围与级联；静态照明是否烘焙需另外验证六阶段的灯光变化和可移动物件。
3. 对仍昂贵的模型、材质及绘制批次做针对性优化，保留可近距离观察的线索细节。
4. 将低渲染比例作为低配置画质选项。它目前的收益小于镜面和阴影，不应先靠降低清晰度解决。
5. 完成后以相同路径复测，再测移动、物件查看、录音、转场和结束流程。目标优先稳定帧耗时，不能仅报告平均 FPS。

上述修改尚未应用到正式场景。测试只修改独立进程内的设置，结束后退出。
