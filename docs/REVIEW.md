## 在原作品集之外补齐的内容

1. 交互遮挡与身体碰撞的区分，以及视线几何缓存。
2. 音频、字幕、记录与发现是不同状态，避免重复触发或提前透露。
3. 双语与阅读设置的作用范围，说明偏好保存不等于存档。
4. 服务认证、会话容量、超时、错误路径与离线运行的差异。
5. 构建日期、打包日期、源码快照和试玩附件的区别。
6. 性能失败方案与待查问题，防止只呈现最好看的数字。
7. 制作来源与可执行代码的证据索引。

## 审阅发现及处理

| 发现 | 本次处理 | 尚需什么 |
|---|---|---|
| 旧 README 把 Windows.zip 指向源码包 | 新建明确命名的离线试玩 Release，删除旧 Release 及附件 | 后续保持文件名与实际内容一致 |
| 旧资料仍把 AllSky / 原外壳写成当前主要实现 | 文档区分历史使用与后续程序化替换 | 完整发行依赖与逐资产授权清单 |
| 性能跨轮数据容易被当成单次 A/B | 主表改用 124.7 → 157.2 的同轮结果 | 最新试玩的可见窗口复测 |
| headless 日志有无图形渲染器警告 | 明确该检查只验证启动与所筛异常，不证明渲染正常 | 图形启动和完整人工通关 |
| 旧资产清理记录还有 missing-script 项 | 只保留为历史待复核事项，不宣称已全部清零 | 在当前 Unity 场景中重新扫描并逐项判断 |
| 个别普通物件没有后期预录变体 | 说明运行时只显示存在的变体，不擅自补写台词 | 作者决定是否需要增加内容 |
| 制作材料之间存在不同年代的来源表述 | 采用最新要求的简短 AIGC 说明，避免逐项绝对化声明 | 如未来发布详细制作来源，再按资产补齐 |

## 后续工作优先级

**发行验收**：在可见图形模式下从标题到结尾完整试玩，覆盖中英文、第二阶段翻转发现、离线提示、暂停后的阅读确认、钥匙开门、退出与重启。另在一台没有开发环境的机器上解压运行。

**性能复核**：复现铁罐周期性长帧、行走长帧和其余音频首次播放；保持场景、视角和构建一致，报告 P95 与最长帧。

**工程维护**：重新扫描 missing script、模型导入参数与引用；为发行建立固定的版本 / 构建清单。当前公开快照只是讲解代码，不能替代完整工程的可重现构建。

**素材与作品集**：补齐技术概览视频与完整通关录像；本次使用已有制作图，不把 Figma 中视频占位视为已经完成的成果。

这些是待做项，不计入本次已完成的测试。本次没有为补文档改写游戏逻辑、录音或阶段揭示时机。
