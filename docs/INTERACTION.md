# 交互、声音与界面

[文档目录](README.md)

## 交互循环

玩家接近物件 → 准星与轮廓反馈 → 查看 / 物件动作 → 聆听录音或发现细节 → 更新记录 → 询问物件或与房间交谈 → 读完回复后继续。

普通陈设与关键线索共享观察体验，但只有规定的线索和实物发现参与推进。不能让每个可点击物件都自动变成谜题，也不能由悬停描边直接泄露当前答案。

## 移动碰撞与点击遮挡分开处理

用于阻挡身体的 collider 可能包住椅腿之间、柜体开口等空隙。若把这些体积直接作为交互遮挡，玩家会看得见物件却点不到。

InteractionOcclusion 对可见几何作精细测试：将射线转换到相应空间，先测试按 96 个索引分组的 bounds，再测试组内三角形。几何缓存避免每帧重新读取和组织网格；变换与几何必须对应当前物件状态。

这不是允许穿墙点击，而是把“阻挡身体”和“阻挡视线”两个问题分开。边界浮点舍入也可能改变命中结果，因此优化 bounds 构建时保留原有 Encapsulate 的舍入顺序，并提供诊断开关对比旧实现。

## 检视并非单一旋转按钮

查看系统包含近距离副本、原地观察和专属交互路径：纸张翻转、书中抽信、电话听筒、窗体开合、枕头触碰、水壶开盖等各有表现。大型陈设通常原地查看，避免为了统一交互而把整个房间家具搬到镜头前。

视觉动作、声音与事实记录各有职责。比如纸背墨迹只有在实际观察条件满足后才进入 discoveries；普通查看记录只描述已见内容，不预先写出心理结论。水壶内文字是后期可选细节，不额外增加通关门槛。

## 声音分成三层

| 声音层 | 作用 | 实现边界 |
|---|---|---|
| 线索录音 | 传递既定台词与伴随声 | 已导入 AudioClip，非运行时生成 |
| 环境声 | 连续塑造阶段气氛 | 阶段切换时淡出 / 换片段 / 淡入；六段环境音使用 Streaming |
| 操作与引导声 | 拿起、开合、触碰及方向提示 | 程序合成或已有素材；不播放未发现的台词 |

孩子的录音声音使用 ElevenLabs 预先制作；实时语言模型回应以文字显示。两者不能混写成“玩家说一句，系统实时生成配音”。

ClueSoundLure 只针对当前阶段尚未完成的目标，在查看、对话、菜单或结尾时暂停；优先使用指定伴随声，缺少时用已有操作声或合成短声。进度显示与“我不知道该看哪里”选项提供另一条引导途径，但不会替玩家完成发现。

## 转场必须等待阅读确认

服务端或离线回放给出完成状态后，客户端设置 pendingStage / pendingEnding，展开回应面板。等待 expanded 和 MenuOpen 都结束，再执行对应转换。暂停或设置本身不是“我已读完”的确认动作。

最终叙事完成先使出口可用；玩家主动使用钥匙、门逐渐消失、走出门槛后才淡出与进入结束页。走廊光的出现时机与六阶段收束相关，不属于额外线索。

## 双语与可读性

界面提供中文 / English，字体为思源宋体。阅读字号有 1.0、1.2、1.4 三档，设置通过 PlayerPrefs 保存。语言变化更新可选界面文本，不重置已听录音和发现；已有对话保留当时原文。录音保留中文原声，字幕与记录提供相应语言文本。

这些是现有可读性功能，不足以声称已通过完整无障碍认证。尚需覆盖长英文换行、字幕时机、焦点与键盘操作、不同分辨率以及各类输入设备。当前发布也不承诺跨次启动保存叙事进度；PlayerPrefs 保存偏好不等于保存完整游戏状态。
