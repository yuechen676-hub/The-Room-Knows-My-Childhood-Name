# AI 叙事系统：自由表达与阶段规则

[文档目录](README.md) · 本页包含叙事结构与推进细节。

## 为什么不让模型直接控制游戏

玩家可能用关心、质疑、试探或不完整的表达接近主题。纯关键词匹配容易要求玩家猜出开发者的措辞；完全让模型决定阶段，又可能在证据不足时提前推进或揭露后续内容。

当前系统把自然语言解释交给模型，把阶段状态和可检查条件保留在服务端。模型提供回复与结构化评估，Python 核对引用、已听录音、已见事实和本阶段要求，再决定是否更新阶段。这个结构约束推进，但不构成对模型语义判断的独立证明。

## 一次输入如何经过系统

| 步骤 | 数据与处理 |
|---|---|
| Unity 收集 | text、language、recovered_memories、discoveries 与 session_id |
| 服务整理 | 当前阶段、近期对话、合法证据与提示词 |
| 模型返回 | 文本回复、理解评估、证据引用和回应引用 |
| 规则检查 | 引用是否存在于实际发言 / 回复，线索是否已发现，阶段条件是否满足 |
| 状态保存 | 保留已经取得的理解；模型失败不凭空推进 |
| 客户端展示 | 展示回复，阶段完成后等待阅读确认，再改变环境表现 |

后端使用不同阶段评估器：stage_one、stage_two、later_stages。历史分数或轮数不能单独成为通关依据。模型上下文只传允许使用的发现；程序不信任客户端提交的任意“细节解释”，而是依据合法发现标识组织已知事实。

## 情绪约束如何进入技术条件

底层事实是孩子用安慰性说辞保护自己、回避现实，但早期不要求完整承认“我在撒谎”。第一阶段可以接受玩家察觉安慰的需要；第二阶段接受对说辞与实物冲突的局部让步；后期才逐渐增加揭示力度。

同阶段探索顺序自由。先表达有效理解、后补齐录音时，理解不应丢失；反过来，听完录音也不自动等于理解。测试覆盖“全部录音 + 问候不能推进”“提前理解可保留”“虚构引用不能取得理解”等情形。

## 失败与重试

结构不合法、引文不在原始输入、或部分阶段回应违背约束时，服务代码有针对性重试。仍无法获得有效结果时返回可重试错误并保留已取得的进展，不能把服务失败当作剧情沉默或完成。

旧聊天历史与玩家当次输入区分处理，避免把此前的模型评估 JSON 当作本次玩家证据。上下文截取控制长度，但服务器内存会话不是持久化存档；服务重启后无法承诺恢复。

客户端 HTTP 超时设为 125 秒，服务端模型客户端配置为 45 秒且 SDK 自动重试关闭。应用级重试仍可能增加等待，不能把这两个值解释成实际响应时间保证。

## 服务接口与资源边界

serve.py 的包装包含 X-Room-Token 验证、16 KB 请求体限制、会话锁、最多两个并发生成容量、默认每小时 120 次计数和最多 32 个会话；清理会话的空闲阈值为两小时。健康检查可独立公开，但不会因此开放游戏接口。

这些是当前代码边界，不是完成负载测试的结论。会话存于内存，没有多进程共享持久化。试玩采用离线模式，因此不依赖这套服务在线。

## 从独立分类器到当前方案

早期做过 TF-IDF + Logistic Regression 四分类原型，标签为 accepting、questioning、recognizing、rejecting。保存的资料记录 1,228 条 AI 生成标注语句，75% / 25% 分层划分，307 条留出测试中 252 条正确，即 82.1%；五折交叉验证记录为 81.2%，标准差 2.8 个百分点。

作者后来认为单句分类过于刻板，放弃将它作为当前判断方式，转向结合阶段、证据和近期交流的模型评估与规则检查。这是开发取舍，不是经过真人对照实验证明 LLM 必然更好。早期志愿者语句已丢失，不能将现存 82.1% 归于那批数据。

本次引用依据是现有分类器过程核对记录，未重新训练或反序列化旧模型。完整工程中的原始过程记录为 `SubmissionPlanning/classifier-process-notes.md`。

## 离线版如何保留这些约束

离线录制在真实会话的分支上进行，只向服务提供该选项出现时必然已经获得的信息。运行时按同样的可见条件显示选项，再回放对应回复和 closes 判定。它不在线理解自由输入，也不覆盖所有可能回复。

当前有 54 条台词定义与 77 个回复变体；“77”是数据条目数，不能解释为 77 段语音文件或 77 次已完成玩家测试。详见[离线对话与接口](DIALOGUE.md)。

## 本次回归验证

2026-11-05 在本地环境运行 7 个 test_*.py 文件，共 **66 个测试，通过 66 个**。覆盖阶段规则、观察记录、请求包装、会话与异常路径。测试使用替身响应，不调用真实模型。

错误路径测试会打印模拟的 invalid model output / Connection error；最终 unittest 为 OK，不是两项测试失败。规则测试通过不代表全部真实模型回复通过叙事审查，也不代表六阶段 Unity 人工通关。
